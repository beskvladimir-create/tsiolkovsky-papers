# Tsiolkovsky Papers

Making the archive of Konstantin E. Tsiolkovsky machine-readable.

Konstantin Tsiolkovsky (1857–1935) derived the rocket equation, described the
multistage rocket, the orbital station and the space elevator, and worked out
the physics of spaceflight decades before anyone could test it. His personal
archive — **fond 555 of the Archive of the Russian Academy of Sciences** — has
been scanned and put online: **1,979 files, 31,680 pages** of manuscripts,
drafts, calculations and correspondence.

It is scanned, but it is not readable by a machine. There is no catalogue you
can query, no full-text search, no dataset. This repository is the pipeline
that changes that.

## The gap this closes

*Issledovanie mirovykh prostranstv reaktivnymi priborami* ("The Exploration of
Cosmic Space by Means of Reaction Devices", 1903) is the founding paper of
astronautics. As of July 2026 its text does not exist in machine-readable form
in any open source we could find — not on Russian Wikisource (91 other
Tsiolkovsky works are there), not in the digitised collected works. The
manuscript is in fond 555, file 45, as 126 scanned images.

The same holds for *Kosmicheskiy korabl'* ("The Spaceship", files 46 and 47,
two variants, 359 pages) and most of the rocketry core of the fond.

## What we measured

**Legibility.** A manual reading test on file 33 (article "The Reaction Device
as a Means of Flight in Vacuum and in Atmosphere", autograph, c. 1905) across
four page types put confident legibility at **75–85%** on pages of running
text: archival covers and headings read almost without loss, faded ink and
authorial strikethroughs are the hard cases. Full report in
`ОТЧЁТ_А0_читаемость.md` (Russian).

**Page composition.** `classify_pages.py` measures every scan without a neural
network — printed baselines are evenly spaced, handwriting is not — at 18 ms
per page. Over 8,970 pages of opis 1:

| Class | Pages | Share |
| --- | ---: | ---: |
| Handwritten | 7,714 | 86% |
| Typewritten / printed | 931 | 10% |
| Notes and archival covers | 325 | 4% |

This matters for cost: only the handwritten 86% needs a vision model. The
typewritten tenth is ordinary OCR work, and the classifier's contrast metric
also isolates the ~1.5% of faded pages that the legibility test identified as
hardest, so they can be handled separately.

## Contents

| File | What it does |
| --- | --- |
| `tsiolkovsky_downloader.py` | Retrieves scans. Parses each file's page, falls back to the URL template, resumes, retries, validates JPEG structure, maintains the catalogue |
| `classify_pages.py` | Per-page metrics: ink coverage, text-line count, baseline regularity, contrast |
| `export_catalog.py` | Builds `catalog.json` and the priority list |
| `catalog.csv` / `catalog.json` | The catalogue: opis, file number, title, material type, dates, page counts, link to the source page |
| `priority.csv` | The rocketry core, selected by title — 56 files, 3,075 pages |

Scans are not in this repository (13 GB). Transcripts are held back until the
corpus and the accompanying paper are ready for release together.

## Reproducing

Python 3, standard library only, plus `numpy` and `pillow` for the classifier.

```bash
python3 tsiolkovsky_downloader.py --opis 1 --only 33   # one file
python3 tsiolkovsky_downloader.py --full --to 2000     # the whole fond
python3 classify_pages.py                              # page metrics
python3 export_catalog.py                              # catalogue + priority list
```

The downloader runs **one request at a time** with a pause between them. This
is a public archive's server and it is not robust; please do not parallelise
it.

## Method

Automated transcription produces a **useful draft**, not a finished scholarly
edition. Uncertain readings are marked `[?]`, unreadable passages
`[неразборчиво]`, authorial deletions are preserved. This follows normal
digital humanities practice: machine transcription, explicit marking of
uncertainty, selective expert verification of significant passages.

Accuracy will be reported as a measured figure, not an estimate. Where a
manuscript in the fond corresponds to a text published on Russian Wikisource,
including its pre-reform-orthography variants, the transcription can be scored
against that text character by character.
